# Full Circle Food Icon Reference Pack

Use these as reference/starter SVGs for the app. All icons use a `24 × 24` viewBox, `currentColor`, `fill="none"`, rounded caps/joins, and ~`1.8` stroke width.

## Design rules

- Keep silhouettes simple enough to read at 18–24 px.
- Prefer one recognizable object per icon.
- Avoid text, labels, logos, or brand-specific marks.
- Use `currentColor` so theme colors can be applied in CSS.
- Keep food-category icons visually consistent rather than photorealistic.
- If Claude improves/redraws an icon, preserve the existing filename/key.

## Claude Code instruction

Treat these SVGs as starter/reference assets. You may refine individual paths for visual consistency, but do not rename icon keys without also updating the icon mapping. Preserve `viewBox="0 0 24 24"`, `currentColor`, and the common stroke style. Use the generic fallback when classification is unknown.
