This is a beta. It isn’t on Google Play yet, so it has to be installed by hand, and Android will ask you to allow it. Expect rough edges, and tell us what you find.

How to install

  1. Tap Download for Android on your phone and open the file when it finishes (or find it in Downloads).
  2. If asked, allow your browser or file manager to install unknown apps. This is a one-time prompt from Android.
  3. Tap Install. If Play Protect warns about an unrecognised app, choose Install anyway.
  4. Open Fitresh and log in with your existing account.
Good to know

The app loads fitresh.com, so features and fixes reach you automatically without reinstalling. A new APK is only needed for changes to the app shell itself, and we’ll post it here. Open the app online once so it can cache itself for offline use.
